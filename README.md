# Hakata

A tiny GPUI desktop app.

## Prerequisites

- Rust 1.96+
- Xcode with the Metal Toolchain component:
  `xcodebuild -downloadComponent MetalToolchain`

## Run

```sh
cargo run
```

## Build

```sh
cargo build
```
